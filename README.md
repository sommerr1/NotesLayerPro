# Notes Layer Pro - Chrome Extension MVP

Chrome расширение для создания аннотаций и AI-вопросов прямо на веб-страницах.

## Установка

1. Скачайте или клонируйте этот репозиторий
2. Откройте Chrome и перейдите в `chrome://extensions/`
3. Включите "Режим разработчика" (Developer mode)
4. Нажмите "Загрузить распакованное расширение" (Load unpacked)
5. Выберите папку с расширением

## Настройка

### Иконки

Создайте иконки для расширения:
- `icons/icon16.png` - 16x16 пикселей
- `icons/icon48.png` - 48x48 пикселей  
- `icons/icon128.png` - 128x128 пикселей

Можно использовать любые иконки или создать простые цветные квадраты для тестирования.

### Quill.js

Скачайте Quill.js библиотеку:

1. Перейдите на https://quilljs.com/download/
2. Скачайте Quill (минифицированная версия)
3. Распакуйте и скопируйте файлы:
   - `quill.min.js` → `lib/quill.min.js`
   - `quill.snow.css` → `lib/quill.snow.css`

Или используйте CDN версию (потребуется изменить manifest.json):

```json
"content_scripts": [
  {
    "matches": ["<all_urls>"],
    "js": [
      "content/anchor.js",
      "content/highlighter.js",
      "content/note-card.js",
      "content/content.js"
    ],
    ...
  }
]
```

И загружать Quill динамически в `note-card.js`.

## Использование

1. **Создание заметки**: Выделите текст на любой странице, появится кнопка "📝 Create Note"
2. **Просмотр заметки**: Кликните на иконку заметки рядом с выделенным текстом
3. **Редактирование**: Откройте карточку заметки и используйте rich-text редактор
4. **Задать вопрос AI**: В карточке заметки нажмите "Ask Question", введите вопрос и получите ответ от Gemini через Google Search
5. **Поиск**: Откройте popup расширения (иконка в панели инструментов) для глобального поиска по всем заметкам
6. **Экспорт**: В popup нажмите "Export to JSON" для экспорта всех данных

## Структура проекта

```

├── background/
│   ├── background.js         # Service worker
│   ├── db.js                 # IndexedDB операции
│   ├── llm-provider.js       # Абстракция LLM
│   └── google-search-provider.js # Google Search провайдер
├── content/
│   ├── content.js            # Основной content script
│   ├── anchor.js             # Якорение заметок
│   ├── highlighter.js        # Подсветка текста
│   ├── note-card.js          # Карточка заметки
│   └── content.css           # Стили для content script
├── popup/
│   ├── popup.html            # Popup UI
│   ├── popup.js              # Логика popup
│   └── popup.css             # Стили popup
├── ui/
│   ├── note-card.html        # Шаблон карточки
│   ├── note-card.css         # Стили карточки
└── lib/
    ├── quill.min.js          # Quill.js (нужно скачать)
    └── quill.snow.css        # Стили Quill (нужно скачать)
└── icons/                    # Иконки (нужно создать)
```

## Особенности MVP

- ✅ Создание заметок на выделенном тексте
- ✅ Rich-text редактор (Quill.js)
- ✅ Два режима: Annotation и Question
- ✅ Интеграция с Google Search для AI ответов
- ✅ Восстановление заметок при изменении DOM
- ✅ Система предупреждений (yellow/red) для неточных якорей
- ✅ Глобальный поиск по всем заметкам
- ✅ Экспорт данных в JSON
- ✅ Локальное хранение в IndexedDB

## Известные ограничения

- AI ответы получаются через парсинг Google Search (может быть нестабильным)
- Quill.js нужно скачать отдельно
- Иконки нужно создать самостоятельно
- Некоторые сайты могут блокировать content scripts

## Разработка

Для разработки:

1. Внесите изменения в код
2. Перейдите в `chrome://extensions/`
3. Нажмите кнопку обновления (↻) для расширения
4. Обновите страницу, на которой тестируете
