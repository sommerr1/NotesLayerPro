# Libraries

## Quill.js

Download Quill.js from https://quilljs.com/download/

Required files:
- `quill.min.js` - Minified Quill library
- `quill.snow.css` - Snow theme stylesheet

After downloading, place both files in this directory.

Alternatively, you can use a CDN version by modifying the content scripts to load Quill dynamically.
