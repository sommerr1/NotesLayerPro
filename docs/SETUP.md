# Инструкция по настройке

## Шаг 1: Установка Quill.js

1. Перейдите на https://cdn.quilljs.com/1.3.6/quill.min.js
2. Сохраните файл как `lib/quill.min.js`

3. Перейдите на https://cdn.quilljs.com/1.3.6/quill.snow.css
4. Сохраните файл как `lib/quill.snow.css`

Или используйте команды (если у вас установлен curl):

```bash
cd "lib"
curl -O https://cdn.quilljs.com/1.3.6/quill.min.js
curl -O https://cdn.quilljs.com/1.3.6/quill.snow.css
```

## Шаг 2: Создание иконок

Создайте простые PNG иконки или используйте онлайн-генератор:

1. Создайте 3 PNG файла:
   - `icons/icon16.png` (16x16)
   - `icons/icon48.png` (48x48)
   - `icons/icon128.png` (128x128)

2. Можно использовать простые цветные квадраты для тестирования

Или используйте онлайн-генератор иконок для расширений Chrome.

## Шаг 3: Загрузка расширения

1. Откройте Chrome
2. Перейдите в `chrome://extensions/`
3. Включите "Режим разработчика" (Developer mode) в правом верхнем углу
4. Нажмите "Загрузить распакованное расширение" (Load unpacked)
5. Выберите папку `Notes Layer Pro`

## Шаг 4: Проверка

1. Откройте любую веб-страницу
2. Выделите текст
3. Должна появиться кнопка "📝 Create Note"
4. Кликните на неё и создайте заметку
5. В открывшейся карточке заметки введите текст аннотации
6. Аннотация сохраняется автоматически через 500мс после того, как вы перестали печатать

### Как проверить, что аннотация сохранилась:

1. Введите текст в редакторе аннотации
2. Подождите 1 секунду (автосохранение происходит через 500мс)
3. Закройте карточку заметки (кликните × или кликните вне карточки)
4. Кликните на маркер (подсвеченный текст) снова
5. Карточка должна открыться с сохраненным текстом

## Устранение проблем

### Ошибка "Quill is not defined"
- Убедитесь, что файлы `lib/quill.min.js` и `lib/quill.snow.css` существуют
- Перезагрузите расширение в `chrome://extensions/`

### Ошибка "Icons not found"
- Создайте иконки в папке `icons/`
- Или временно закомментируйте секцию `icons` в `manifest.json`

### Content script не работает
- Проверьте консоль разработчика (F12) на странице
- Убедитесь, что расширение активно в `chrome://extensions/`
- Попробуйте перезагрузить страницу

### AI ответы не работают
- Google Search может блокировать автоматические запросы
- Попробуйте другой вопрос
- Проверьте консоль background service worker в `chrome://extensions/` → "Service worker" → "Inspect"

### Аннотации не сохраняются
1. Откройте консоль разработчика на странице (F12)
2. Проверьте наличие ошибок в консоли
3. Проверьте консоль background service worker:
   - Перейдите в `chrome://extensions/`
   - Найдите "Notes Layer Pro"
   - Нажмите "Service worker" → "Inspect"
   - Проверьте наличие ошибок или сообщений "Annotation saved successfully"
4. Убедитесь, что база данных инициализирована:
   - В консоли service worker должно быть сообщение "Notes Layer Pro: Database initialized"
5. Попробуйте перезагрузить страницу и создать заметку заново
6. Если проблема сохраняется, проверьте, что все файлы расширения загружены правильно
