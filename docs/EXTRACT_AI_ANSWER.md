# Извлечение текста ответа ИИ

## Описание

Функция позволяет автоматически извлечь текст ответа ИИ между вопросом пользователя и полем ввода на странице чата/диалога.

## Использование

### Через контекстное меню

1. Откройте страницу с чатом (например, Microsoft Copilot, ChatGPT и т.д.)
2. Убедитесь, что на странице есть вопрос и ответ ИИ
3. Щелкните правой кнопкой мыши на странице
4. Выберите пункт меню **"🤖 Extract AI Answer"**
5. Текст ответа будет автоматически скопирован в буфер обмена
6. Появится уведомление с информацией о количестве извлеченных символов

### Программно (через код)

```javascript
// В content script
const extractedText = notesLayerInstance.extractAIAnswerBetweenQuestionAndInput();

// Или с указанием конкретных элементов
const questionElement = document.querySelector('[role="article"]:last-of-type');
const inputElement = document.querySelector('input[type="text"]');
const extractedText = notesLayerInstance.extractTextBetweenElements(questionElement, inputElement);
```

## Как это работает

1. **Автоматический поиск элементов:**
   - Функция пытается найти последний вопрос пользователя
   - Затем ищет поле ввода
   - Использует различные селекторы для разных чат-интерфейсов

2. **Извлечение текста:**
   - Находит общий родительский контейнер
   - Проходит по всем текстовым узлам между элементами
   - Фильтрует видимые элементы
   - Объединяет текст с сохранением структуры

3. **Очистка текста:**
   - Нормализует пробелы
   - Сохраняет разрывы абзацев
   - Удаляет лишние пустые строки

## Поддерживаемые селекторы

### Для вопроса:
- `[role="log"] > [role="article"]:last-of-type`
- `[class*="message"][class*="user"]:last-of-type`
- `[class*="question"]:last-of-type`
- `[data-role="user-message"]:last-of-type`
- И другие...

### Для поля ввода:
- `input[type="text"]`
- `textarea`
- `[contenteditable="true"]`
- `[role="textbox"]`
- `input[placeholder*="Задайте вопрос"]`
- И другие...

## Ограничения

- Функция работает лучше всего на страницах с четкой структурой чата
- Для динамических страниц (SPA) может потребоваться небольшая задержка
- Если элементы не найдены автоматически, можно передать их вручную

## Примеры использования

### Создание заметки из извлеченного текста

```javascript
// Извлечь текст
const aiAnswer = notesLayerInstance.extractAIAnswerBetweenQuestionAndInput();

if (aiAnswer) {
  // Создать заметку с этим текстом
  // (требует дополнительной реализации)
  console.log('Extracted:', aiAnswer);
}
```

## Технические детали

Функция использует:
- `TreeWalker` API для обхода DOM
- `compareDocumentPosition` для определения порядка элементов
- Фильтрацию видимых элементов через `getComputedStyle`
- Автоматический поиск через множественные селекторы
